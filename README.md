# Pokémon Blaze Black 2 Redux Field Guide

The deployment repository for an offline-friendly Pokémon Blaze Black 2 Redux v1.4.1 field guide.

**Open the guide:** https://jimineybillybob1.github.io/pokemon-blaze-black-2-redux-field-guide/

On iPad, open the guide in Safari, tap **Share**, then choose **Add to Home Screen** to install it with the dedicated Redux icon.

The published guide includes the full National Pokédex, encounters, trainer battles, moves, items, gifts, trades, tutors, legendary encounters, and team-planning tools. The repository intentionally contains only the finished website bundle; working documentation, caches, and build internals remain outside the public deployment.

Data is based on the official Redux v1.4.1 documentation, the pinned [Blaze Black / Volt White 2 Redux Wiki](https://smilingzero.github.io/BlazeBlack2ReduxWiki/), and a pinned PokéAPI fallback.
